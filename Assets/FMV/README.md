# FMV Demo 与素材制作

打开 `Assets/Scenes/FMVDemo.unity`，点击 Unity Play。现有角色使用 `Assets/FMV/Sequences/视频16.asset` 制作配置；开场播一次，随后循环待机。旧工具的起止时间已迁移。

## 后续素材的完整流程

入口：**Tools → FMV → 素材制作工作台**。旧的“待机循环调节器”入口也打开同一窗口。

1. 点击 **新建配置…**，给角色或动作命名；默认保存在 `Assets/FMV/Sequences`。已有配置可拖到“制作配置”栏，或在 Project 选中后点击“读取选中的配置”。同一视频的不同动作可“另存为新配置”，生成的素材互不覆盖。
2. 把 Unity 已导入的 VideoClip 拖到 **原视频**。若原片无法被 Unity 导入，点击 **导入视频文件并转换为兼容格式…**，选择磁盘中的视频，再选择兼容副本保存位置。工具生成 H.264 / AAC 的 MP4 副本并自动选中它，不修改原文件。
3. 拖动时间轴，或输入“定位到（秒）”，用上一帧 / 下一帧精调。设置 **开场起点、开场终点、待机起点、待机终点**；每个字段旁的“取当前帧”可直接取预览位置。两个区间独立，允许跳过原片不需要的头尾或中间部分。“让开场终点接到待机起点”用于连续衔接。
4. **预览开场**、**循环预览待机**检查动作与声音。“看待机起点 / 末帧”用于比较姿势。终点是排除边界，不包含该帧。窗口显示原始画面；原片跳转可能有停顿，最终接缝请以场景中生成片段的播放为准。
5. 选择声音开关和输出帧率。默认保留开场语音，待机无声；勾选“保留待机声音”后，每次待机循环都带声音。无音轨的源视频也能正常生成并播放。
6. 点击 **生成 / 更新这份配置的素材**，等待完成。首次生成在配置旁创建独立的 `<配置名>_Media` 文件夹，包含 `Intro.mp4`、`Idle.mp4`、`Poster.png`。更新同一份配置会替换这三个文件，保留资产引用。窗口会提示素材是否与当前切分设置一致。
7. 将 Hierarchy 中角色的 **RawImage** 拖到“目标角色”，或选中角色点击“使用 Hierarchy 中选中的角色”。需要新角色时，选中 Canvas 或其子物体，点击“在选中的 Canvas 下新建角色”；再用 RectTransform 调整位置与大小。
8. 选择是否使用绿幕抠像，设置绿幕阈值、边缘柔化、去绿强度。点击 **把生成素材配置到目标角色**：自动补齐两段 VideoPlayer、独立 AudioSource、RenderTexture 和首帧预览，并绑定这份制作配置。已有角色的位置与大小保留，其他角色不会被自动替换。
9. 点击 **保存目标角色所在场景**，或 Ctrl+S，然后 Unity Play 验证。运行时开场只播一次，待机原生循环；空格暂停 / 继续，R 重播开场。这两个调试快捷键会作用于所有启用的 FMV 角色。

配置改动自动保存到各自的 `.asset`，再次打开仍能继续制作。“从目标角色读取制作配置”可以找回该角色对应的原片与切分设置。重新切分后先生成，再配置场景；仅调整抠像参数时不用重新生成视频，直接配置场景即可。同一配置绑定多个角色时，它们共享片段和抠像材质，但每个角色使用独立画面纹理。

生成有阶段提示和取消按钮；生成过程中关闭窗口、重编译脚本或进入 Play 会中止任务。两个视频和首帧均生成成功才替换现有输出；失败不会先覆盖旧片段。生成操作不使用 Undo，场景配置支持 Undo。

## Demo 场景

森林背景和 UI 来自 `Assets/Resource/images/BG.png` 与 `UI.png`，按最终效果图布局，2736 × 1536 构图，窗口比例不同时留黑边。在 `FMVCanvas/Composition_16x9` 调整 Background、CharacterLoop、Interface 的布局。

角色用两个播放器分别输出画面。开场期间预加载待机，切换时保留开场末帧，待机首帧到达后替换纹理。绿幕只在显示时抠像，导出视频仍保留绿幕，便于后续调整。

`视频8示例.asset` 是另一份素材的制作示例，展示独立区间、30fps 输出以及独立声音开关，不影响现有视频16角色。旧 `Video16Intro.mp4` 等文件保留，当前场景已使用配置对应的新输出。

Windows 制作端使用项目自带 `Tools/Video/ffmpeg.exe`，无需单独安装；播放和打包后的运行时不依赖制作工具或 Unity Pipeline。Demo 目前只展示界面和角色动画，未接入剧情或菜单业务逻辑。
